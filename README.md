# simulacro-eunacom-2026
Simulacro EUNACOM 2026 para practicar por temas del temario.

## Seguimiento de pautas

El total se calcula sobre las 4.298 preguntas del banco. Se considera cubierta una pregunta con una explicación clínica en texto, incluidos los comentarios breves del banco. Quedan pendientes las preguntas con solo la clave o sin explicación clínica. Tener pauta y contar con una referencia MINSAL verificada son indicadores distintos.
